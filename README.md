# EPICENE SALON & SPA — Professional Website (Upgraded)

Modern, mobile-first salon website based on the original student price-list flyer.

## Live site
https://mawelanoah.github.io/EPICENE/

## What’s included
- `index.html` — full single-page website
- `style.css` — brand styling (charcoal, deep red, gold/yellow)
- `script.js` — mobile menu, dynamic booking form, WhatsApp integration
- This README

## Features
- Sticky header + category navigation
- Exact student prices from the flyer
- Photo cards for each service category
- Interactive booking form:
  1. Select category
  2. Select specific service / length
  3. See the listed price
  4. Enter name, date, time + notes
  5. Send formatted WhatsApp request to 068 286 7446
- Floating WhatsApp button
- Back-to-top button
- Fully responsive (mobile-first)
- SEO-friendly title & meta description
- No backend, no paid services — works on GitHub Pages

## How to publish / update on GitHub Pages
1. Replace the files in your existing repository root with these three files.
2. Commit and push to the `main` (or `master`) branch.
3. GitHub Pages will update automatically (Settings → Pages → Deploy from branch → `/ (root)`).

## Important notes
- All prices are student discount rates taken from the original flyer.
- The booking form only sends a WhatsApp request — the salon must confirm availability.
- No physical address or opening hours are shown (not provided on the flyer).
- Images are high-quality Unsplash stock photos that can be replaced with the salon’s own photos later.
