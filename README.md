# EPICENE SALON & SPA — flyer-style website demo

This version intentionally follows the supplied flyer: charcoal/black background, red section bars, white price panels, yellow accents, student discount headline, and the same service categories and contact details.

## Files
- `index.html`
- `style.css`
- `script.js`

## Publish with GitHub Pages
1. Create a public repository named `EPICENE-SALON`.
2. Upload these three files to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)` → Save.

## Before making it public
Please ask the salon to verify every price, spelling, and contact detail. The appointment form sends a WhatsApp request to 068 286 7446; it does not confirm or store bookings. The flyer does not provide a physical address or opening hours, so those have not been added.
